# Веб-приложение по организации выставок 

**Exhibitions** — веб-приложение для поиска, просмотра и организации выставок. Проект объединяет каталог культурных мероприятий, интерактивную карту и инструменты для управления выставками.

## Технологический стек

- **Язык:** JavaScript
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **База данных:** PostgreSQL
- **Валидация:** Zod
- **Карты:** Яндекс Карты
- **Геоданные:** Wikidata, GeoJSON
- **Дополнительно:** WebSocket, SMTP, Git

## Этапы разработки

### Этап 1. Базовая инфраструктура и каталог выставок — реализован

- Проектирование и создание базы данных PostgreSQL.
- Разработка серверной части на Node.js и Express.js.
- Реализация REST API для работы с выставками, городами и категориями.
- Импорт справочника городов Беларуси из Wikidata.
- Получение и хранение географических координат и контуров городов.
- Создание клиентской части на React.
- Реализация каталога с поиском, фильтрацией и сортировкой выставок.
- Интеграция Яндекс Карт с отображением выставок и географических границ.

### Этап 2. Пользовательская система — планируется

- Регистрация, авторизация и подтверждение электронной почты.
- Управление профилем пользователя.
- Личный список выставок.
- Подача заявок на добавление выставок.
- Подписки на города и категории.

### Этап 3. Система уведомлений — планируется

- Уведомления о новых выставках.
- Настройка пользовательских подписок.
- Отправка уведомлений по электронной почте.
- Получение уведомлений в реальном времени через WebSocket.

### Этап 4. Административная панель — планируется

- Модерация заявок на добавление выставок.
- Создание, редактирование и удаление выставок.
- Управление учетными записями пользователей.
- Просмотр статистики приложения.

### Этап 5. Тестирование и развёртывание — планируется

- Проверка работоспособности основных функций.
- Тестирование API и пользовательских сценариев.
- Обработка ошибок и оптимизация производительности.
- Подготовка документации и развёртывание приложения.

## Назначение проекта

Приложение предназначено для организации и управления выставками, предоставляя организаторам инструменты для размещения мероприятий, а посетителям — возможности поиска интересующих выставок и планирования их посещения.
